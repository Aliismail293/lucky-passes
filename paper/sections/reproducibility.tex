\section*{Reproducibility Statement}
% Drafted by Claude. Ali: check the commands still work from a fresh clone (Phase 7 does this for the pilot).
All code, configurations, per-question results (\texttt{results/*/records.jsonl}) and summaries
(\texttt{results/*/summary.json}) are released at \url{https://github.com/Aliismail293/lucky-passes}. Every model
runs locally through Ollama at temperature 0 with a fixed seed, and every model call is cached on disk, keyed by a
hash of the model, prompt and decoding parameters, so a stopped run resumes where it stopped. Question samples use a
fixed seed. Three commands reproduce the pilot (\texttt{uv sync}; \texttt{uv run python scripts/download\_data.py};
\texttt{bash scripts/overnight.sh pilot}); \texttt{bash scripts/overnight.sh full} runs the core grid and the
$k$-sweep. Every table and figure in this paper is generated by \texttt{scripts/make\_paper\_assets.py} from the
summaries, and \texttt{scripts/check\_numbers.py} fails the build if the paper contains a number that does not
appear in a results file. Exact outputs can still differ across Ollama versions and hardware.
